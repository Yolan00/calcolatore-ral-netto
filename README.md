# Calcolatore RAL → Netto (anno d'imposta 2026)

Prototipo che, data una RAL, calcola il netto annuo e mensile di un dipendente e mostra il dettaglio di tutte le voci trattenute sul lordo.

Caso modellato: dipendente privato a tempo indeterminato, residente a Milano (Lombardia), nessuna agevolazione particolare.

**Stato: in costruzione.** Questo README verrà sostituito al passo 9 con flusso di calcolo, tabella parametri, semplificazioni adottate e limiti noti.
